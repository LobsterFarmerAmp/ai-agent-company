# 组织架构示例

> 以下是一个 5 人 AI Agent 公司的组织架构示例，展示如何使用 `company-org-chart` 技能定义团队结构。

## 等级体系

Boss（人类决策者）为 0 级，超脱于技能分配之外，拥有最高决策权。

| 等级 | 权限 | 成员 |
|------|------|------|
| 1 级 | 可向 2 级发布任务和指令，管理各自领域 | 首席架构师、首席技术官 |
| 2 级 | 执行任务，不发布任务，服从上级指令 | 数据工程师、后端工程师、文案策划 |

## 架构图

```
Boss（CEO）[0级]
├── 首席架构师 [1级]
│   职责：平台治理、Agent 配置管理、技能系统、定时任务
│   上级：Boss（直接汇报）
│
└── 首席技术官 [1级]
    职责：项目管理、任务分配、对外对接
    上级：Boss（直接汇报）
    │
    ├── 数据工程师 [2级]
    │   上级：首席技术官（直接主管）
    │
    ├── 后端工程师 [2级]
    │   上级：首席技术官（直接主管）
    │
    └── 文案策划 [2级]
        上级：首席技术官（直接主管）
```

## 设计要点

### 1. 管理跨度

- 每个管理者直接管理 2-3 个执行者
- 管理者也是执行者（1 级也要做实际工作）
- 避免过多的管理层级（目前只有 3 层：0 -> 1 -> 2）

### 2. 职责划分

- **首席架构师**：管平台、环境、治理规则、技能系统
- **首席技术官**：管项目、业务、任务分配、对外对接
- 两者平级，各管一摊，不互相指挥

### 3. 技能分配

| 技能 | 1 级 | 2 级 | 说明 |
|------|------|------|------|
| company-dialogue | ✅ | ✅ | 跨 agent 对话 |
| company-reporting | ✅ | ✅ | 工作总结 |
| company-org-chart | ✅ | ✅ | 组织架构 |
| company-task-dispatch | ✅ | - | 派发任务 |
| company-task-execution | ✅ | ✅ | 执行任务 |
| company-code | ✅ | ✅ | 代码规则 |
| self-improvement | ✅ | ✅ | 经验记录 |
| persona-audit | ✅ | ✅ | 人设审查 |

关键设计：
- **dispatch 只给 1 级**：2 级不能派活，只能执行
- **execution 给所有人**：1 级也可以执行任务（自上而下或跨域协作）

### 4. 通信规则

- 所有 Agent 间通信走目标 Agent 的 **main session**（单世界线原则）
- 正式任务走 Workboard（有状态、可追踪）
- 日常沟通走 sessions_send
- 方案审阅走 Company Board discussion 帖

### 5. 扩展建议

- **2-3 人团队**：1 个 Boss + 1 个管理者 + 1 个执行者，去掉架构师角色
- **5-8 人团队**：保持当前结构，增加 2 级执行者
- **8+ 人团队**：考虑增加 1.5 级（team lead），但会增加通信复杂度
