# 公司组织架构

> 权威基准，由架构师维护。

## 等级体系

Boss为 0 级，超脱于技能分配之外，拥有最高决策权。

| 等级 | 权限 | 成员 |
|------|------|------|
| 1 级 | 可向 2 级发布任务和指令，管理各自领域 | 架构师、CTO |
| 2 级 | 执行任务，不发布任务，服从上级指令 | 数据工程师、后端工程师、文案策划 |

## 架构图

```
Boss- CEO [0级]
├── 架构师 - OpenClaw 首席架构师 [1级]
│   职责：环境治理、agent 配置管理、技能系统、定时任务
│   上级：Boss（直接汇报）
│
└── CTO - 首席技术官 [1级]
    职责：项目管理、任务分配、对外对接
    上级：Boss（直接汇报）
    │
    ├── 数据工程师 - 数据分析平台开发与运维 [2级]
    │   上级：CTO（直接主管）
    │
    ├── 后端工程师 - Backend Engineer [2级]
    │   上级：CTO（直接主管）
    │
    └── 文案策划 - 策划文案助手 [2级]
        上级：CTO（直接主管）
```

## 关键关系

- **架构师 ↔ CTO**：平级（均为 1 级），各管一摊。架构师管系统/环境，CTO管项目/业务
- **数据工程师 / 后端工程师 / 文案策划**：2 级，直属CTO管理，服从 1 级指令
- **所有人**：最终服务 Boss（0 级）
