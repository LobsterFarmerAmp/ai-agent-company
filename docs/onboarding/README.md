# Onboarding Notes（入职熟悉笔记）

> 治理仓库的下一次部署完整指南补遗——每位新员工入职熟悉阶段产出的笔记归档处。

## 目录约定

| 文件 | 命名 | 作者 |
|------|------|------|
| 治理-入职熟悉笔记-宪章.md | 治理规范专员视角 | xian-zhang |

## 用途

- 沉淀新人对公司硬规则、治理仓库结构、Company OS 工具族的实际理解；
- 把实战中发现的疑问点和建设性优化建议沉淀为可治理的输入；
- 治理岗（xian-zhang）定期把高优建议提报 PR 到 `codex/main-agent-architect`，由架构师 review。

## 阅读顺序

新治理岗入职时：
1. 先读 `../../README.md` 与 `../{overview,architecture,governance,maintenance}.md`；
2. 再读 `../../templates/*` 对照自身五件套；
3. 最后读本目录笔记，对照实战场景。

## 维护

- 新人笔记以 `*-<姓名>.md` 命名，按提交先后自然排序；
- 不在笔记中写入明文密钥、cookie、token；
- 笔记中的"建议"如被采纳，需在 commit 信息中引用本笔记文件名，便于追溯。
